# 文档命名规范

## 基本规则

- 标题应简洁、稳定，直接说明文档主题。
- 文档类型、文档版本、适用系统版本和生效时间放入元数据，不在标题中重复维护。
- 长期有效文档标题不写日期。
- 会议纪要、周报、月报、公告、巡检报告等事件型文档在标题中写日期。
- 不使用“最新版”“最终版”“终极版”等无法校验的描述。
- 同一主题不通过复制并改名的方式生成多个权威版本。

## 推荐格式

长期有效文档：

```text
文档主题
```

事件型文档：

```text
YYYY-MM-DD 文档主题
```

平台如需显示分类前缀，应根据元数据中的`文档类型`自动生成，不要求作者手工维护。
