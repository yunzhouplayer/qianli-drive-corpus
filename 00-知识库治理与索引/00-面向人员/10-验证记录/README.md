# 验证记录

本目录保存知识库治理、权限、安全和平台接入的脱敏验证记录。验证记录用于说明特定时间、范围和条件下实际验证了什么，不替代生产运行日志、飞书审计日志或业务审批记录。

## 记录要求

- 只记录实际执行和可复核的结果，不把模拟测试当作真实平台能力。
- 不保存 App Secret、访问令牌、完整资源 Token、完整飞书链接、人员权限明细或业务正文。
- 明确验证范围、未验证范围、运行模式、失败过程和最终结论。
- `governance_validation` 阶段不得使用“生产接入完成”“权限同步完成”或“生产索引可用”等表述。
- 原始响应只在受控临时位置短暂保存并及时清理；本目录只保存脱敏摘要。
