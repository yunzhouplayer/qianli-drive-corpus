# 2026-08-13 飞书知识库单节点只读与权限变更验证报告

## 1. 结论

P0 单节点只读接入与资源权限变更闭环验证通过。

企业自建应用能够读取已授权知识库节点，并被飞书拒绝读取未授权节点。撤销原测试节点的有效阅读权限后，该节点读取返回权限拒绝；重新授予阅读权限后恢复成功。应用认证在权限变化期间保持有效，说明应用身份认证与具体资源授权是相互独立的控制层。

本结论只适用于本次单节点、应用身份、只读验证，不代表用户级权限同步、完整变更审计、批量同步、生产索引或 Agent 检索能力已经建立。

## 2. 验证范围

|项目|本次范围|
|---|---|
|运行模式|`governance_validation`|
|生产索引|`production_index_enabled=false`|
|身份类型|企业自建应用的 `tenant_access_token`|
|接口|知识空间节点信息只读接口|
|正向样本|一个无敏感信息且向应用授权的测试节点|
|反向样本|一个未向应用授权的对照节点|
|权限变化|授权、撤权、恢复授权|
|正文读取|未执行|
|飞书写操作|未执行|

验证设计见[飞书知识库单节点只读烟测设计](../../../docs/superpowers/specs/2026-08-13-feishu-readonly-node-smoke-design.md)。

## 3. 安全控制

- App Secret 保存在 macOS 钥匙串中，未写入仓库、命令行参数或报告。
- `tenant_access_token` 只存在于烟测进程内，报告只记录是否获取成功及有效期。
- 两个节点链接保存在 macOS 钥匙串中，报告只使用不可逆短哈希引用。
- 未请求文档正文，未调用创建、移动、修改、归档或删除接口。
- 原始接口响应使用权限为 `600` 的临时文件短暂解析，退出前全部清理。
- 真实烟测前使用本地模拟服务验证了缺配置保护、正向读取、反向拒绝、输出脱敏和临时文件清理。

## 4. 测试结果

节点脱敏引用：

- 正向节点：`7065ce241d`
- 反向节点：`0e2ce4763d`

|阶段|正向节点|反向节点|判定|
|---|---|---|---|
|初始授权|HTTP 200、`code=0`，读取成功|HTTP 400、`code=131006`，权限拒绝|通过|
|首次声明撤权后复测|连续两次仍为 HTTP 200、`code=0`|保持 `code=131006`|撤权尚未形成有效访问收紧|
|有效撤权后复测|HTTP 400、`code=131006`，权限拒绝|保持 `code=131006`|权限收紧通过|
|恢复授权后复测|HTTP 200、`code=0`，读取恢复|保持 `code=131006`|权限恢复通过|

应用认证在各阶段均成功。首次成功认证返回的令牌有效期为 7200 秒；权限变化过程中应用认证没有失效，但节点访问结果随资源授权变化。

## 5. 元数据字段验证

节点可读时，接口能够返回或确认以下治理所需字段：

- 对象类型：`docx`。
- 节点类型：`origin`。
- 是否存在子节点。
- 文档所有者和创建者字段是否存在。
- 文档创建时间、最近编辑时间和节点创建时间是否存在。
- 标题字段是否存在。

为避免泄露测试内容和人员信息，报告不保存标题、人员标识、完整节点 Token、空间 ID 或文档对象 Token。

## 6. 事实、判断与限制

### 6.1 已验证事实

1. 应用凭证能够换取有效的 `tenant_access_token`。
2. 已授权节点可以被应用身份读取。
3. 未授权节点持续返回 `131006 permission denied`。
4. 有效撤权后，原可读节点变为权限拒绝。
5. 恢复授权后，原节点重新可读。
6. 权限变化不要求应用凭证失效才能生效。

### 6.2 治理判断

- 飞书 API 权限范围与具体知识库资源授权应作为两层独立门禁管理。
- 仅凭认证成功不能登记“知识库可访问”；必须保留具体资源的正向和反向验证证据。
- 权限收紧应进入后续同步与失效处理测试，确保派生数据不会继续暴露已撤权内容。

### 6.3 未验证范围

- 未精确测量权限变更传播时延。首次撤权复测仍可访问，但人工权限操作过程没有统一时间戳，无法判断是权限继承、操作未完全移除还是传播延迟。
- 未验证用户身份权限、用户与应用权限的交集或权限组继承。
- 未验证权限成员列表、逐次变更审计、事件订阅和历史版本。
- 未验证批量节点遍历、附件、正文、表格、图片或其他文档类型。
- 未验证生产索引、权限过滤检索、引用校验和 Agent 回答。

## 7. 门禁判定

|门禁|结果|
|---|---|
|已授权节点读取成功|通过|
|未授权节点读取被拒绝|通过|
|必要节点元数据可获取|通过|
|无正文读取和写操作|通过|
|凭证、Token 和完整资源标识未进入报告|通过|
|临时响应已清理|通过|

P0 最终判定：`通过`。

允许进入下一阶段的单文档治理试点，但仍必须保持：

- `operating_mode=governance_validation`；
- `production_index_enabled=false`；
- `06-corpus-manifest.yaml` 为空；
- 三个 AI 权限均为 `false`。
