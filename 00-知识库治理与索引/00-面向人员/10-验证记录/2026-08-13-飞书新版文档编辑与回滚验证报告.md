## 4. 安全与回滚控制

1. 真实写入前完成本地模拟测试，证明只创建一次、只删除一次且结构可恢复。
2. 目标节点先经只读检查确认可访问、对象类型为 `docx`，对照节点仍被权限机制拒绝。
3. 新增请求使用独立幂等键和明确文档版本号。
4. 删除目标根据创建响应返回的唯一块 ID 定位，不使用“最后一个块”等位置猜测。
5. 删除前重新读取当前版本和根块子块列表；只有移除新增块后与原列表完全一致才执行删除。
6. App Secret、访问令牌、完整节点链接、完整文档和区块标识均未进入仓库或报告。

## 5. 能力边界

### 已验证

- 应用对指定测试文档具有真实编辑能力。
- `docx` 文本块可通过 API 创建并读取验证。
- 新增块可按当前索引受控删除。
- 使用文档版本和区块 ID 能够实现最小可回滚写入。

### 未验证

- 未验证新建知识库空间或修改空间设置。
- 未验证创建、移动或删除知识库节点。
- 未验证 Markdown 到飞书复杂区块的完整转换。
- 未验证批量导入、断点续传、重跑幂等和失败回滚。
- 未验证表格、图片、附件、公式、画板及其他复杂块。
- 未验证飞书历史版本是否满足完整逐次变更审计要求。

## 6. 后续门禁

允许进入治理规则和 Skill 的真实试点，但批量导入前仍需完成：

1. 定义本地目录与飞书知识库节点的确定性映射。
2. 明确哪些仓库文件允许导入，排除 `.git`、凭证、运行日志和本地配置。
3. 验证知识库节点创建、标题、父子关系和幂等重跑。
4. 对两个 Skill 分别运行准备与独立审查，修复实测缺陷。
5. 建立导入清单、失败记录、重试规则和导入后完整性校验。
