# 权限与安全规范

## 权限原则

- 权限按“空间 → 目录 → 文档”继承，例外授权记录申请人、审批人、理由和失效时间。
- `01-公司公共知识库`只有公共目录默认全员只读；战略、经营会议等内容按目录授权。
- 中心或部门空间默认本中心可读或评论，正式文档由负责人和维护团队编辑。
- 项目成员仅在协作期获得编辑权限，项目结束后收回。
- AI Agent 使用与当前用户相同或更小的权限，不得借助平台管理员或索引服务账号扩大可见范围。
- 用户无权访问时，不得通过搜索或 Agent 暴露标题、摘要、命中数量或内容是否存在。

## 安全等级

|等级|适用说明|默认处理|
|---|---|---|
|公开级|已经批准可对外公开的信息|按需开放索引和回答引用；训练默认关闭|
|内部级|仅限公司员工访问的普通内部信息|按业务需要开放；训练默认关闭|
|机密级|商业秘密、核心策略、敏感合作和重要经营信息|安全审批后入库；AI 权限默认关闭|
|限制级|隐私、轨迹、财务核心、密钥证书、核心算法等高敏感内容|原则上不入通用知识库；AI 权限默认关闭|

安全等级描述敏感程度，原始数据描述内容形态，二者不得混为同一分类。

## 禁止原始入库

- 未脱敏的手机号、身份证、精确定位、行程和支付信息。
- 财务明细、薪酬绩效明细和未公开预算。
- 核心算法源代码、密钥、证书和访问令牌。
- 未脱敏或未经审批的合同、政府沟通材料和商业报价。
- 可反推出用户身份、车辆轨迹或运营安全策略的原始数据。

知识库只保存口径、规则、流程、脱敏摘要和受控源系统链接。无法证明脱敏不可逆或无法控制重识别风险时，不得入库。
