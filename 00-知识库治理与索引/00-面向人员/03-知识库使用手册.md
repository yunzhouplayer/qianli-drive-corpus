# 知识库使用手册

## 创建文档

1. 确认内容应归属的责任空间和目录。
2. 搜索是否已经存在同主题权威文档；已有文档时优先更新或引用。
3. 按[文档命名规范](./05-文档命名规范.md)设置标题。
4. 按[AI 友好内容写作规范](./09-AI友好内容写作规范.md)组织正文、边界、术语和引用。
5. 按[元数据填写规范](./06-元数据填写规范.md)填写元数据。
6. 根据[权限与安全规范](./07-权限与安全规范.md)设置初始权限和安全等级。
7. 可调用[`prepare-knowledge-document`](../02-Skills/prepare-knowledge-document/SKILL.md)整理候选元数据和正文缺口；具体调用语法由 Agent 客户端决定，该技能不代表准入审批。

## 评审与发布

1. 文档负责人完成自检后，将权威状态改为“评审中”。
2. 内容审批人确认内容、适用范围和生效时间；敏感内容须增加安全审核。
3. 评审通过后，将权威状态改为“正式”，有效状态按生效时间设置。
4. 正式文档默认只读，文档负责人和维护团队保留受控编辑权限。
5. 需要供 Agent 使用时，按[索引准入与同步规范](../01-面向AI/04-索引准入与同步规范.md)单独审批。
6. 提交管理员前，调用[`review-knowledge-admission`](../02-Skills/review-knowledge-admission/SKILL.md)执行独立审查；管理员确认和业务审批不得由任何 Agent 代替。

当前处于治理验证模式时，审查结论最高为“治理验证通过”，不得执行真实生产索引或宣称文档已经入库。

## 更新与废弃

- 重大内容变更须更新文档版本、修订记录、更新时间和复审日期，并重新评审。
- 错误或存在风险的正式文档应先暂停引用，再修订或废弃。
- 废弃时必须填写替代文档或废弃原因，并触发索引清理。

## 项目结束

- 项目过程资料归档只读。
- 长期有效的制度、业务规则、方案、接口和 SOP 转移到责任空间。
- 协作空间保留过程记录及正式成果链接。
