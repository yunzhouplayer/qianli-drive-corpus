# 索引准入与同步规范

> 当前运行模式为“治理验证”，生产索引关闭。本规范现阶段仅用于检查规则完整性，不执行真实文档索引、Agent 回答引用或模型训练。

本文说明人员可读原则；机器执行以[03-index-admission-rules.yaml](./03-index-admission-rules.yaml)、[13-indexing-policy.yaml](./13-indexing-policy.yaml)和相应 Schema 为准。

## 准入

1. 默认拒绝进入生产索引。
2. 从飞书权威源读取正文、文档元数据值和实时 ACL，再使用 Git 权威 Schema、字典和准入规则进行校验。
3. 任一必填字段不合格、来源无权限信息或源文档不可访问时拒绝准入。
4. 限制级内容默认拒绝；机密级内容必须具有明确的安全审批记录和限定用途。
5. 单次决定按[准入决定 Schema](./schemas/13-admission-decision-schema.yaml)写入运行审计；批准发布的索引 generation 可生成[06-corpus-manifest.yaml](./06-corpus-manifest.yaml)受控快照。实时连接器和索引状态仍保存在 Git 之外。

## 分块与解析

- 每个分块继承文档ID、章节路径、ACL、安全等级、文档版本、更新时间和 AI 处理权限。
- 不生成无来源分块，不把目录名或文件名猜测为业务事实。
- 表格、图片、附件和扫描件解析后保留页面或附件定位。
- 无法可靠解析或无法定位来源的内容不得自动形成事实答案。

## 更新与失效

|源文档事件|索引处理|
|---|---|
|正式发布且准入通过|创建生产索引并记录源版本和同步结果|
|正文或元数据更新|重新处理受影响分块，旧版本停止召回|
|到达复审日期|进入待复审状态；超过宽限期后停止回答引用|
|暂停、废弃或过期|停止回答引用并移除生产索引|
|权限收紧|立即按新 ACL 阻断检索并清理超范围缓存|
|源文档删除|按保留要求清理索引、缓存、摘要和图谱关系|

权限收紧和敏感信息下架立即生效，并在 1 小时内完成派生索引清理；普通更新和废弃在 1 个工作日内完成同步。

## 审计

索引准入、同步、拒绝、清理失败和权限异常必须记录时间、文档ID、源版本、执行主体、结果和失败原因。

审计事件必须符合[运行审计事件 Schema](./schemas/10-runtime-audit-event-schema.yaml)，真实事件写入 `00-知识库治理与索引/.runtime/` 或批准的外部日志平台，不提交 Git。

正文或权限与 Git 副本、索引副本不一致时，以飞书权威源为准并停止使用过期派生数据；机器规则发生冲突时，以 Git 已批准版本为准。同步流程不得反向覆盖任一权威源。
