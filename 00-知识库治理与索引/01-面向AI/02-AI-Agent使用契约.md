# AI Agent 使用契约

## 默认来源

Agent 只能默认使用同时满足以下条件的内容：

- 当前用户具有源文档访问权限。
- `authority_status=formal`。
- `effective_status=effective`。
- `ai_permissions.allow_index=true`。
- `ai_permissions.allow_answer_citation=true`。
- 文档已经通过索引同步且来源状态正常。

## 使用规则

|规则|要求|
|---|---|
|非正式知识|草稿和评审中文档仅在用户明确发起评审时使用，必须标注状态，不得作为制度、流程或公司事实依据|
|权限校验|检索前按用户身份和源文档 ACL 过滤，生成后再次校验全部引用|
|引用|回答返回文档ID、标题、文档版本、生效时间、适用范围和源文档链接|
|冲突|先按主题ID和适用范围查找权威来源，再比较有效状态、生效时间和版本；无法判断时停止下结论|
|时效|过期、暂停、废弃或同步异常的内容不得作为默认依据|
|敏感内容|不得通过摘要、改写、跨文档拼接或多轮对话绕过权限和安全等级|
|无依据|检索不到明确来源时说明依据不足，不自行补全公司事实|
|输出|优先返回结论、依据、来源、适用范围、限制条件和待确认项|

用户无权访问某内容时，Agent 不得暴露其标题、摘要、命中数量或存在性。
