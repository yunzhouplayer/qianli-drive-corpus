# 知识库治理与索引

本空间与各业务知识空间平级，由知识治理、检索平台和安全相关专业人员共同维护。它只保存公司级知识库规范、机器控制文件和治理模板，不承载各中心业务正文。

```text
00-知识库治理与索引/
├── 00-面向人员/
├── 01-面向AI/
└── 02-Skills/
```

## 02-Skills

保存遵循开放 Agent Skills 规范的知识治理技能权威源码。不同 Agent 的安装副本只用于发现和运行，不作为维护来源。

- [知识入库准备 Skill](./02-Skills/prepare-knowledge-document/SKILL.md)：补齐候选元数据、正文结构和安全边界，不批准入库。
- [知识入库审查 Skill](./02-Skills/review-knowledge-admission/SKILL.md)：独立检查准入规则，通过后引导管理员完成受控操作。
- 每个技能以标准 `SKILL.md` 为入口，`references/` 和 `scripts/` 按需加载；`agents/openai.yaml` 仅为 OpenAI/Codex 可选界面适配器。
- 分发时复制完整技能目录到目标 Agent 客户端配置的技能路径，不只复制 `SKILL.md`；安装路径和调用语法由客户端决定。
- 技能源码和各 Agent 安装副本均不得进入公司生产知识索引。

## 维护原则

- 人员侧规范说明“为什么”和“怎么做”；AI 侧文件定义“机器如何判断”。
- 同一规则只保留一个权威定义，其他文件使用链接引用。
- 本空间的目录、Schema、索引规则和权限模型由专业维护人员变更，业务空间管理员通过变更申请参与。
- 业务域、系统平台、权威来源和评测问题不得由知识库管理员代替业务负责人填写。
- 向量索引、缓存、自动摘要等运行数据不进入本目录。
