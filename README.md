# 千里智行公司知识库治理库

本项目当前保存公司知识库的机器治理控制、自动化实现，以及用于首次创建的人员规范和模板种子，不保存各中心的实际业务文档、原始数据或运行索引。正式创建后的公司知识正文、文档级元数据值、权限和页面版本以飞书知识库为权威来源；Git 以机器 Schema、字典、准入规则、稳定 ID 和发布清单为权威来源。

当前运行模式为“治理验证”，生产索引和 Agent 公司知识回答均未启用。

飞书正文发布采用默认拒绝的显式清单。Git 中的测试记录、Schema、脚本和 Skill 源码不会因为文件扩展名相同而自动发布；正文页面首次创建并移交飞书后，Git 种子变化不得自动覆盖飞书内容。
